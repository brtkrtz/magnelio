How-to guides
=============

Task-oriented recipes on the public API.  Each page solves one
concrete engineering problem end to end and is meant to be adapted
rather than read in order: download it as a ``.py`` script or a
``.ipynb`` notebook and edit the parameters at the top for your own
device.  For a guided introduction to the workflow itself, start with
the tutorials instead.
